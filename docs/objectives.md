# Objectives

Upon completing this laboratory experiment, students will be able to:

* **Understand Static Signatures:** Understand the core concept of a static virus signature, byte sequence identification, and cryptographic hash matching.
* **Identify Behavioral Indicators:** Analyze common runtime behavioral indicators exhibited by malware (process spawning, unauthorized file encryption, startup persistence, command-and-control communication, and security policy tampering).
* **Perform Signature Scans:** Perform simulated signature scans against a structured threat repository.
* **Perform Behavioral Inspection:** Perform simulated dynamic behavioral analysis and calculate weighted risk levels.
* **Synthesize Verdicts:** Synthesize findings from both static signatures and dynamic behavioral indicators into a combined detection verdict (Clean, Suspicious, or Malicious).
* **Understand Evasion & Defense-in-Depth:** Demonstrate why behavioral analysis is indispensable when detecting zero-day and polymorphic threats that evade static signatures.
